# SCU-Matrix

ATLAS SCU — gestionale per Servizio Civile Universale.

Frontend statico su GitHub Pages con backend Google Apps Script e database Google Sheets.

## Moduli previsti
- Dashboard
- Calendario
- Operatori SCU
- OLP
- Assenze e permessi
- Formazione
- Scadenze e adempimenti
- Impostazioni

## Sicurezza
Il repository non deve contenere dati personali, password, codici fiscali, IBAN o altri dati sensibili. I dati applicativi risiedono nel backend Google Sheets/Apps Script.
